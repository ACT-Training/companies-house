# Fixtures

These are **synthetic** Companies House responses, hand-written in the shape of the real API. The companies, people and
numbers are fictional. They were written without an API key, so they have not been checked against a live response.

Replace them with real responses recorded once with a dev key, as the spec asks. Cover active, dissolved, in
liquidation, renamed and Scottish (SC prefix) companies. Before committing a recording, redact officer and PSC personal
data: names, dates of birth, nationality, addresses and officer appointment links.

Prettier ignores this directory so recordings stay byte-for-byte.
